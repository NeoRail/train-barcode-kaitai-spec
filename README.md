# Kaitai Spec for Train Barcodes

[Kaitai Struct](https://kaitai.io/) specifications for train ticket barcodes.

Covered ticket barcodes here are either reverse engineered to put into a machine-readable from
based on official documentation.

Not covered here are ticket barcode formats that already have another type of machine-readable
specification, such as [UIC's ASN.1 specification](https://github.com/UnionInternationalCheminsdeFer/UIC-barcode/tree/master/asn-specs)
or [SBB's protobuf specifiction](https://github.com/TheEnbyperor/zuegli/blob/root/main/swisspass/swisspass.proto).

For more information about the wonderful world of train ticket barcodes see also
the [Train Ticket Wiki](https://trainticket.wiki/).
